# Dual Fist Arena — Timing Stickman Brawler

**在线体验 / Play online:** https://pipygames.com/games/dual-fist-arena-timing-stickman-brawler-545c

Walk, jump and punch through 40 stickman arenas. Every opponent telegraphs a cue — punch inside that window and the hit lands, swing early and you eat the counter. Dodge sweeps, break armour, parry overheads, chain perfect hits. Five chapters, one new verb at a time, ending with a boss that changes its own rules three times. Free in your browser.

## 技术栈 · Tech stack

- 引擎 / Engine: **Phaser**
- 其他 / Also: Canvas 2D 图层
- 语言 / Language: 中文 + English
- 部署 / Hosting: 纯静态，index.html 即入口，直接丢到任意静态空间即可
